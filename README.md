# RegistryCleaner

Программа на C++ (WinAPI) для поиска и очистки устаревших записей об удалённых программах в реестре Windows.

## Возможности

- Сканирование разделов `Uninstall` (HKLM 64/32-bit, HKCU)
- Определение «осиротевших» записей: нет папки установки или деинсталлятора
- Разделение находок по степени уверенности
- Резервное копирование ключей в `.reg` перед удалением
- Создание точки восстановления системы

## Сборка (MinGW)

```
g++ -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8 src/main.cpp -o RegistryCleaner.exe -ladvapi32 -static
```

Для создания точки восстановления запускайте от имени администратора.

## Предупреждение

Программа изменяет реестр. Используйте на свой риск, всегда проверяйте список перед удалением.
